# 試す文の一覧と、期待する結果

`probes/` の文は、過去の変更で副作用を見つけた文と、各ルールが拾うべき典型の文を集めたもの。1行1文なので、`compare.py` の出力の行番号から文がすぐ分かる。

この一覧だけで確かめると、一覧に入っている文でしか確かめないことになる。一覧は出発点として流し、変更ごとに新しい文も書く。新しい文で副作用が見つかったら、ここに足す。

## 照合（verify）用

`pairs/before/` と `pairs/after/` の同じ名前のファイルが、書き換え前と書き換え後の組。

| ファイル | 書き換え | 期待する終了コード |
| --- | --- | --- |
| `same-kanji-number` | 一回 → 1回 | 0（同じ数） |
| `same-kanji-days` | 十四日 → 14日 | 0 |
| `idiom-hitorihitori` | 一人ひとりに聞く → 全員に聞く | 0（慣用句は数えない） |
| `idiom-ichinichijuu` | 一日中 → 終日 | 0 |
| `idiom-juubun` | 十分にある → 足りている | 0 |
| `reworded-only` | まず最初に → まず | 0 |
| `changed-count` | 三回 → 5回 | 1（値が変わった） |
| `changed-unit` | 30日以内 → 30日未満 | 1 |
| `added-number` | 速く → 10msで | 1（原文にない数値） |
| `quote-kanji` | 「一回だけ」→「1回だけ」 | 1（引用は一字一句守る） |
| `code-kanji` | `retry 一回` → `retry 1回` | 1（コードは一字一句守る） |
| `capability` | 返金できます → 返金します | 3（可能が実施に変わった） |
| `negation` | しません → します | 3（否定が消えた） |
| `added-unsourced` | 「一般的に、」を足す | 3（根拠のない前提が増えた） |

```bash
P=.claude/skills/check-polish-side-effects/probes
for f in $P/pairs/before/*.md; do n=$(basename $f); polish-japanese verify $f $P/pairs/after/$n >/dev/null; echo "$n $?"; done
```
